# 🧩 Biznest - Fullstack Service Provider Platform

**Biznest** is a real-world, full-stack platform that connects customers with local service providers like electricians, plumbers, cleaners, and more. It offers a secure and seamless experience for users to discover, book, and review services — with dedicated roles for customers, service providers, and admins.

Built with **Angular (Frontend)** and **Node.js + Express (Backend)**, and designed to be scalable, maintainable, and production-ready.

---

## 🚀 Features

### 👤 User Module
- User registration & login (JWT-based)
- Role-based access (Customer, Provider, Admin)
- Update profile & password

### 🛠 Service Provider Module
- Create & manage service listings
- Upload images & details
- View bookings & reviews

### 📋 Customer Module
- Browse services by category
- Book appointments
- View booking history
- Submit feedback & ratings

### 🛡 Admin Panel
- Manage users, services, and bookings
- View system-wide analytics
- Moderate reviews
